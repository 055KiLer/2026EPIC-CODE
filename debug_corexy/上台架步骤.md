## 1. 上台架前 5 分钟：确认"板上跑的就是这份固件"

- [ ] 核心板由 **DAPLink 对插 2×5P 排针**供电/烧录（不要数脚序，直接对插）。
- [ ] USB-TTL：模块 **RX ← 板 PA0**、模块 **TX → 板 PA1**、**GND 共地**（TX/RX 必须交叉）。模块 5V **不接**，电平跳线选 3.3V。**接反了不会烧，只会没数据——一片安静就先对调这两根线**。
- [ ] **串口助手连哪个 COM**：连 **USB-TTL 模块**那个口，不是 DAPLink 的。
      认法：设备管理器 → **端口 (COM 和 LPT)** 里带芯片名的（`USB-SERIAL CH340 (COMx)`、`CP210x`、`CH343`）；
      DAPLink 的虚拟串口通常在"通用串行总线设备"下、显示成 `USB 串行设备`，**且在这块板上没接任何信号，选它一定没数据**。
      最可靠的办法是拔插法：拔掉 USB-TTL → 刷新端口列表 → 少掉的就是它。
      插上后没有新 COM 口 = 缺驱动（装 CH340 驱动）。
- [ ] **这一步先不接 12V、不接舵机**——只上逻辑电，先把控制台打通。

[CFG] 电机 A = USART3 PC10/PC11（M1 座）   电机 B = UART5 PC12/PD2（M2 座）

[HINT]   运动不动时：① 驱动器电源灯 ② 接线 TX↔RX 交叉/共地 ③ `j a cw 30 800 255` 盯电机

[BOOT] 上电自检：逐地址发使能帧看谁应答（不需要先知道 ID）

[ACK]   所以问题不在 MCU 这一侧（不是接线/波特率/引脚），往驱动器参数想

...

**只上逻辑电时（还没接 12V）**：上电自检那两行一定是"没有回包"——这正常，

## 3. 接 12V 与两台电机：先核驱动器 ID

**接线**：电机 A → 板上的 **M1 座（USART3）**，电机 B → **M2 座（UART5）**——每台一路 UART，一条线一台；
驱动器 12V 按板上丝印接，**驱动器电源地必须与板子共地**（不共地会出现"帧发出去了但没人执行"）。

**改 ID 不方便时的快速通道（广播，地址 0x00）**：不需要知道 ID 就能让两台一起动——
```
en 0        # 广播使能（发完手拧两台，都抱死 = 广播有效）
bx 50       # 广播走 X：两台同向同量，龙门整体平移 50mm；方向不对试 bx -50
stop        # 停止（三条线各一帧广播停）
```
⚠️ 广播只能做**两台同向同量 = 纯 X 平移**；**纯 Y / 方块 / 耦合验证必须知道 ID**（下面 §5 那三步要靠它）。

```
> en all
[OK] A线 广播 使能（本批驱动器不回包，属正常）
[OK] B线 广播 使能（本批驱动器不回包，属正常）
[OK] T线 广播 使能（本批驱动器不回包，属正常）
[READY]
```
- [ ] 2026-09-30 定调：全广播、只发不收——**没有 [ACK] 行不是故障**。链路好不好直接用
      运动+眼睛判：`j a cw 30 800 255` / `j b cw 30 800 255`（电机转 = 该线通）；
      想看驱动器"说话"用 `scan`（单播逐 ID，对自己的 ID 回 02）。
- [ ] 敲完 `en all`，**用手拧两台电机的轴**：都拧不动 = 已进使能态（广播对所有台生效）。
      注意**"有回包"与"手拧抱死"是两件事**：回了包但还能拧动 → 驱动器收了帧没执行（模式/固件）；
      没回包但拧不动 → 该 ID 的驱动器在别处（或不应答但照样执行）。
- [ ] 若只有一台抱死、或都不抱死 → 敲 `scan 8`，**靠回包直接找 ID**（不用再逐个手拧等 3 秒）：
  ```
  > scan 8
  [SCAN] 逐 ID 发使能帧，看谁应答（有回包的那个 ID 就是这台驱动器的地址）
  [ACK] 探测 地址1 回包 4 字节: 01 f3 02 6b     ← 有回包 → 有一台就是 ID 1
  [ACK] 探测 地址2 回包 0 字节:
  [ACK] 没有回包 → 这一帧没有任何驱动器应答，按这个顺序查：…
  [ACK] 探测 地址3 回包 4 字节: 03 f3 02 6b     ← 还有一台是 ID 3
  ```
  若一个都不应答 → 改用**手拧法**：逐个 `en <ID>`，发完手拧两台，哪台抱死就是那个 ID。
- [ ] 记录：**A = ID ___，B = ID ___**
- [ ] 若与默认的 1/2 不同：运行时敲 `id a <地址>`、`id b <地址>`（免重烧）→ 再 `en all` 确认。
- [ ] **两台是同一个 ID 时**：按地址发也会两台一起动。想分开控制就得先用厂商上位机改掉其中一台的地址
      （本工程不预置改地址指令，避免猜帧格式）。此时仍可先做广播测试（上面那条快速通道）。

## 4. 单台点动：电机真的会转吗

```
> j 1 cw 30 3200 255
[INFO] 地址 1 CW 3200 脉冲 30 rpm accel=255  估算 2200 ms
[INFO] 帧内速度字段 = 30（`j` 不做系数换算；当前系数 1 只作用于 bx/x/y/xy/sq/cal）
[ACK] 位置 地址1 回包 4 字节: 01 fd 02 6b
[ACK] ✓ 驱动器应答 02 = 命令已正确接收 → 帧确实到了驱动器里，
[OK] 等满 2200 ms（到位判定本就是时间估算，无发送应答）
[HUMAN] 这正好是电机一圈：秒表掐一下，约 2200 ms 说明帧内速度字段就是 RPM，
[HUMAN]   若实测约 10 倍（≈22000 ms）则字段是 0.1RPM —— 改 `spu 10` 并记进待办
```
- [ ] A 电机转**一整圈**（约 2.2 秒）；对 B 也来一次（把地址换成 B 的 ID）。
- [ ] 记录：每台 **CW 时电机轴/皮带轮往哪个方向转**。
- [ ] **听**：有无异响、卡顿；**摸**：驱动器/电机是否发烫（发烫立刻断 12V）。
- [ ] **秒表对一次转速**（这条能定下速度单位，10 倍差）：见下表最后一节。

| 现象 | 先查 |
|---|---|
| 打 `[FAIL] 帧没发出去` | 串口/M1 M2 接线、共地；(发送失败就是纯通信问题) |
| 回包是 `EE` / `E2` | 驱动器说帧不对/参数越界：`EE`=校验或帧长、`E2`=转速/加速度/脉冲越界 |
| 帧发出去了但**一动不动** | 按下面 ①~⑦ 的顺序查，别乱猜 |
| 只**抖一下**不转 | 细分/电流设置、加速档太大、或脉冲数太少 |
| 明显不到一圈 | 细分数不是 16（`Config/sort_config.h` 的 `CFG_PULSE_PER_REV_42` 按 3200 写） |
| 实际耗时≈估算的 **10 倍** | 速度字段单位是 0.1RPM（不是 RPM）→ `spu 10`，并**记进待办**（产品也会慢 10 倍） |

**"一动不动"的排查顺序**（每步都能独立得出结论，别跳步）：

| # | 做什么 | 结论 |
|---|---|---|
| ① | 看驱动器**电源灯**亮不亮；万用表量驱动器 V+ 到 GND 是不是 12V | 不亮/没电压 → 驱动器根本没工作，后面都白搭 |
| ② | `ack 1` / `ack 2`：只发使能帧、打回包（**不运动**） | **回包含 `02` = 帧确实进了驱动器** → 问题在"收到但不执行"（控制模式/固件/参数），跳到 ⑥；**无回包** → 帧没到，走 ③④⑤ |
| ③ | **核对接线**：该线 MCU 侧 TX（A=PC10 / B=PC12）必须接驱动器 **RX**；驱动器 TX 接 MCU 侧 **RX**（A=PC11 / B=PD2）。**TX↔RX 必须交叉，接成 TX→TX 是最常见的错**；再确认共地 | 接反/接错 → 驱动器永远收不到 |
| ④ | `dump` 打印帧字节（不发）核对格式；`loop` 做回环自检：**拔掉驱动器**，把板子总线 TX/RX 用一根线短接，然后跑 `loop` | `loop` 收到自己的字节 = **MCU 发送链路（时钟/引脚/MSP/波特率）全对**，故障在驱动器侧；收不到 = 反过来 |
| ⑤ | `baud 9600` / `19200` / `38400` / `57600` / `230400` 逐档试，每档都 `ack 1` + `en 0` 手拧 | 某一档有回包/抱死 → 驱动器被改过波特率（本板实测可用配置是 115200） |
| ⑥ | 仍不动 → 用**厂商上位机**确认驱动器：控制模式是不是"串口/通讯"（不是脉冲/方向）、固件是不是 **Emm V5.0**、地址是多少 | 模式/固件不对，帧对了也不动 |
| ⑦ | 想彻底排除"我这一侧构帧"：`dump` 打出的整行 `send ...` 直接粘贴执行，把帧原样发出去 | 与 ② 同结果 = 构帧无嫌疑；结果不同 = 告诉我 |

**速度单位（RPM 还是 0.1RPM，差 10 倍）——用秒表定**：

| 命令 | 字段单位是 RPM | 字段单位是 0.1RPM |
|---|---|---|
| `j a cw 30 3200`（正好一圈） | ≈ 2.2 s | ≈ 22 s |
| 之后怎么办 | 不用改（默认 `spu 1`） | `spu 10`，**并把这条写进待办**：产品的速度与所有时间估算都会差 10 倍 |

依据：物创固件把这一节标成「运动速度 (0.1RPM)」，产品 `code/` 按 RPM 算 —— 两边不一致，只能实测定。

| 现象 | 含义 | 改法 |
|---|---|---|
| 四段对、方块闭合 | 方向与耦合都对 | **不用改** |
| X+ 向左、Y+ 向上（两个都反） | 整体 180° | `CFG_AXIS_A_SIGN` 与 `CFG_AXIS_B_SIGN` **同时取反** |

| 单一轴反（X 对、Y 反） | 接线/装配不对称 | 两个符号**无解**，要动硬件（对调那一台的一对线圈） |

## 7. 夹爪 / 升降：先定角装机构，再扫行程定档位

### 7.0 ⚠️ 装机械之前：先把两个舵机定到电中位再装（防堵转）

**这条必须在拧第一颗螺钉之前做。** 机械爪的两个舵机是**各占一路**的（按电控文档 §2：上舵机=升降、
下舵机=开合），谁先被装进机构，谁就先按下面这套定好角。

**为什么**：位置型舵机的电中位是 **1500µs**（早期档位表里那个"半开 1500"就是取电中位；现档位已按机构实测重标——
兜底初夹 = 1750、兜底夹紧 = 1950，见 §7.2）。若连杆/齿轮
先按某个随意角度装上去，之后舵机被指令走到机构到不了的角度，就会**顶死堵转**：机械爪**不装到位开关（R5）**、
驱动器也没有电流检测，代码里没有任何自保护 —— 唯一的表现是嗡嗡响、发烫，堵转电流 1~1.5A，结果是烧舵机或崩齿。

**顺序（一个舵机一次，另一个先 `sstop` 松力）**：

1. 只接一个舵机（先 **H1/PB9 = 夹爪**，产品板丝印为准），**独立 5~6V 供电 + 与板子共地**；堵转 1~1.5A，
   **别用 DAPLink / USB-TTL 的 5V 带舵机**（会把 MCU 拉挂）。
2. 上电 → 固件立刻把两路送到安全位（**夹爪完全张开 1250µs / 升降抬到顶 1600µs**（升降最高档 1200→1600→1650→1600，**10-02 防 1650 到顶堵转回退 50µs**）——**夹爪重装后三次标定（10-01）+ 10-02 回退**后的当前值，随标定迭代，以 `cfg` 打印为准；2026-09-26 首装时是"夹爪 1500 中位、上电不奔极端档"，防机构行程未标定时堵转），别被吓到。
3. `raw claw 1500` → 判型（停住 = 位置型；一直转 = 360° 连续型，见下表）**并让它锁在电中位**。
4. 保持 1500µs 不动，**这时才装连杆/齿轮**。装配基准**二选一**：
   - **中位装法（默认推荐）**：机构摆到**行程中点**（升降 = 中位）。电中位两侧各有一半电行程的余量，
     机构摆幅只要不大于舵机全行程，扫出的两端就一定落在 500~2500 内 —— 最鲁棒。
   - **端点装法（齿轮联动的"半开"没有确定状态时用）**：齿轮啮合是离散的齿，中点常常对不上齿。
     那就装在**完全闭合（或完全张开）**这个唯一确定的状态：先给舵机一个你打算让该端最终用的脉宽
     （**建议 650~700 或 2300~2400，别用 500/2500** —— 给舵机自身留余量，不少 180° 舵机空载打 500/2500 也会顶内部限位嗡嗡响），
     机构贴住该端装好，再往另一方向 ±50µs 扫出另一端。
     **硬约束**：若另一端扫到 ≈2400（或 ≈600）还没到机构端点 = 机构摆幅吃光了剩余电行程，
     这个装配角不成立，拆开往中位方向重装。
   ⚠️ 不要用手强拧已经通电的舵机盘（会让舵机顶着你的手堵转）。
5. 装好后**只往一端**小步试：每次 ±50µs（`raw claw 1550` / `raw claw 1450`），边听边摸，
   找到**刚好到端点**的脉宽；两端各留 **50~100µs** 余量 → 就是 `CFG_CLAW_OPEN_US` / `CLOSE_US`
   （升降同理 `CFG_LIFT_UP/DOWN_US`）。**别一上来就打 500 / 2500**。
6. 每端保持 10s → 摸温度；**任何嗡嗡响 / 发烫 → 立刻 `sstop claw`（立即松力）**，往回退 50~100µs 再试。
7. 换另一个舵机：先 `sstop claw` 让上一个松力，再 `raw lift 1500` 重复 1~6。

> ⚠️ **装完先想一遍"上电那一刻"**：固件上电把夹爪送到 `DBG_CFG_CLAW_BOOT_US`（自 2026-10-01 起 = **直接引用** `DBG_CFG_CLAW_OPEN_US` = 完全展开 **1250µs**）、
> 升降送到 `DBG_CFG_LIFT_UP_US`（= 到顶 **1600µs**）。**这两个值 = 夹爪重装后三次标定（10-01）+ 10-02 防堵转回退的当前值**（升降最高档 1200→1600→1650→1600）。
> 这两个值若落在机构行程之外，就是**每次上电都堵一次**。所以扫出的两端要**直接写回** `Config/dbg_config.h`
> 的 `DBG_CFG_*_US`（调试板）与 `code/Config/sort_config.h`（产品），让安全位本身就在机构行程内。
> ⚠️ **数字跟着机构走，别跟着占位值走**：`OPEN/CLOSE/HALF` 宏名带的是语义，数值按机构实测填 ——
> 端点装法下"开"完全可能是高脉宽（如 OPEN≈2300、CLOSE≈650），与占位值 500/2500 正好对调，这是正常的。

> 已经装错角度的补救：`sstop claw` 先松力 → 拆开/脱开连杆 → 回到本流程第 3 步重来（别硬拧）。

## 8. 限位 / 原点微动开关：接哪三个脚 + `lim` 自检

机械上装的三个微动开关照**产品工程的原引脚**接（`code/Core/Src/gpio.c` 就是这么配的），调试固件用同一组脚：

| 开关 | 信号脚 | 中断线 | 接法 |
|---|---|---|---|
| X 限位 | **PB1** | EXTI1 | COM → GND，NO → PB1 |
| Y 限位 | **PC5** | EXTI9_5 | COM → GND，NO → PC5 |
| 转盘原点 | **PB0** | EXTI0 | COM → GND，NO → PB0 |

（微动开关三个脚：**COM 公共端接 GND**；**NO 常开接信号脚**；NC 不接。）

- 极性与产品一致：**未触发 = 1（内部上拉拉高）、压下 = 0**；固件认的是**压下的下降沿**。
  产品 PCB 上的 4.7k 外部上拉台架上不需要接——内部上拉已经开了。
- 接好后 `lim`（`stat` 里也有一行三路电平的速览）：

```
> lim
[LIM] 未触发=1 压下=0（COM->GND、NO->信号脚，引脚见 dbg_config.h §3.5）
[LIM] X限位  PB1  电平=1(开)  下降沿=2  最近沿=15234ms
[LIM] Y限位  PC5  电平=1(开)  下降沿=0  最近沿=无
[LIM] 转盘原点 PB0 电平=1(开)  下降沿=0  最近沿=无
```

- [ ] 三路电平：不压 = 1，用手压住 = 0。压了还是 1 = 那一路没接通（查 COM/NO 与共地）
- [ ] **沿计数**：压一次 +1（`lim clr` 清零）。**电平对但沿不动 = EXTI 没进来**——
      产品回零靠的是沿不是电平（`调试与推进计划.md` 附录 §5 同一条判据），这条不过就别往下跑回零
- [ ] 平时 0、压下反而 1 = 信号接到了 NC 上，挪回 NO 重接

⚠️ 引脚号（0/1/5）绑定了固件里已开的三条 EXTI 中断线（EXTI0/EXTI1/EXTI9_5，见 `stm32f4xx_it.c`）。
要换线只换 `dbg_config.h` §3.5 的**端口**宏（如 PC5 → PB5），**引脚号别动**，动了要同步改 NVIC 那三行。

## 15. 串口屏（CN2/USART6）+ 视觉（CN3/USART2）联调（1001a 新增）

> 解析器 `k230_uart.c` 是**产品源码原样副本**，屏指令 `tjc_screen.c` 与产品同源——

### 15.1 串口屏（先做，5 分钟出结果）

接线：CN2 → 屏，**PC6(TX)→屏 RX、PC7(RX)←屏 TX（屏不回话可不接）、共地、5V 供电**。
⚠️ **屏端波特率必须在屏工程里设 115200**（TJC 出厂 9600，两边对不上 = 一条指令都收不到）。

1. **屏端单独验（不上固件）**：USB-TTL 接 CN2，串口助手 HEX 发
   `6E 31 2E 76 61 6C 3D 33 FF FF FF`（= `n1.val=3` + 帧尾）→ 第 1 行数字变 3 = 屏工程/波特率/帧尾全对。
2. **固件验**：烧 1001a → `scrtest` → 屏上 6 行"成功数量"自上而下亮 **1,2,3,4,5,6**。
   - 全亮 = 控件名（n1~n6）、行序（=类别 1~6）、USART6 链路全对；
   - **某行不动 = 该控件名在屏工程里不存在**（静默失败，换名字或改 `CFG_TJC_VAR_CNT_BASE/CNT_FIRST`）；
   - `scrtest 0` 清零；`scr n1 5` / `scrp p0 2` / `scrt t0 你好` 单控件点验。
3. [ ] 记录：6 行是否各自 +1（后面视觉联调时放 6 类各一件再复核一遍，那是"类别↔屏行↔盒号"唯一的现场判据）。

### 15.2 视觉（先假帧，再 ROCK 5C）

**① 不接线先验解析与换算（10 秒）**：
```
k230 sim 3 60 45      ← 本地合成"类别3 视觉(60.0,45.0)mm"喂进解析器
k230                  ← 应显示缓存目标 + 换算后机械坐标 + 计数
```
判据：`k230` 打出的"机械系"坐标 = 原点 + 符号×帧坐标（两轴交换：机械 X 取帧 y、机械 Y 取帧 x）。
`CFG_VISION_ORIGIN_* = 0` 时会带 ⚠️ 未标定提示——正常，标定值回填后消失。

**② USB-TTL 假帧（代替 ROCK 5C）**：TTL TX → 板 RX（**PD6**，CN3）、共地；电脑 10Hz 发帧：

```python
import serial, struct, time
ser = serial.Serial('COM7', 115200)          # 换成你的 TTL 口
def frame(cat, x_mm, y_mm, has=True):
    x10, y10 = round(x_mm*10), round(y_mm*10)
    f = bytes([0xAA,0x55,0x01 if has else 0x00,cat,0,0,0]) + struct.pack('<hh', x10, y10)
    ser.write(f + bytes([sum(f) & 0xFF]))    # 校验 = 前 11 字节累加和低 8 位
while True:
    frame(3, 60.0, 45.0); time.sleep(0.1)
```

- `k230 live 10`：应每 100ms 一条"类别 3 视觉(60.0,45.0)->机械(...)"；
- `stat` 的 [VISION] 行：目标帧计数在涨 = 整条接收链路（引脚/中断/解析器/缓存）全通；
- 把 `cat` 改成 7 或给形状字节发非 0：应进"越界"计数、不进"目标"——**这是产品口径的故意设计**
  （旧"颜色×形状"编码漏改时表现为"链路活着但一直无目标"，绝不静默放错盒）。

**③ ROCK 5C 真机**：接 CN3，`/dev/ttyS4`（排针 pin7/29，**不要用 pin8/10**）、termios raw 115200、
持续发流、无目标也照发状态 0x00 帧。判据同 ②；顺带核"物块被拿走后 <2s 目标已切换"。

**台架单件演练（对齐产品读帧纪律，2026-10-01 起）**：`read`（自动走到投放点上方+静默+清缓存+等新鲜帧，给 pick 坐标与形状）
→ `pick X Y 100 <形状0~3>` → `tb <类别>`（2026-10-08 起**双向最近路径**，会打印“正转/反转 N 格”）→ `drop`。★`read` 会顺带给出**产品包络判词**：坐标越界时直接说“产品会按设计作废本件、机器一动不动”——现场“机器不动”先看这条，别在取帧/新鲜度上打转。**1008c 起还打印"钳位后实际落点"并给一条可照抄的 `pick`**（贴边件产品本来就是钳到极限位照夹的，台架 `pick`/`p` 现在同样钳位）。**别在归零/待机位直接 `k230` 当抓取依据**——龙门挡着相机，那时读到的坐标不可信。

**★"无新鲜帧 / 夹爪不去抓"分诊（1008a/1008b 起 `read` 超时给判词 + `k230 raw` 看线上真相）**：
现场口径明确"上位机持续发流、从上电起一刻不停" ⇒ 此时"没有可用的目标帧"只可能是**线级三选一**，不需要猜：

| 证据（跑哪个命令） | 含义 | 修哪里 |
|---|---|---|
| `k230`：**越界**计数在涨 / `k230 raw`：目标帧行带 `[★越界→本机按设计丢弃]`（hex 里能直接看到类别/形状那个数字） | 上位机在报目标，但**类别∉1~6 或形状∉0~3** | 上位机：类别/形状编号（类别 = 屏上行号 1~6；形状 0~3，0=默认方案）。典型是把"认不出"发成了 0/7 之类 |
| `k230`：**无目标**计数在涨 / `k230 raw`：一帧帧全是 `AA 55 00 ...` | 上位机在说"本帧无目标"：**物块在托盘上却没被它当目标** | 上位机：识别 / 目标挑选（典型：被龙门挡过之后没认回来）；`k230 live 20` 盯帧 |
| `k230`：链路=断、三类计数都不涨 / `k230 raw`：**一帧都没组出来**或**全是校验错**（看"散字节"计数） | 帧没到本机：校验/帧长/波特率/接线/上位机 TX | 先并口 TTL 复核线上有没有字节：有 ⇒ 查两边口径（§4.1 帧长 12、累加校验范围）；没有 ⇒ 查线/上位机 |
| `read` 成功后打印的**机械坐标**贴边或落在工作区外 | **不是新鲜度问题**：产品按设计拒绝"够不着"的目标 ⇒ 机器不动（`sort_task.c` 里就写着这条警告） | 把物块往托盘里挪一点（"挪一下就好"的另一种解释）——这条先排除，再查上面三条 |

`read` 的判词还会顺带给出"**清缓存前缓存里有目标、上位机最后一次报它是 Yms 前**" —— 若这个 Y 很小（~100ms）却仍然等不到新帧，
说明流里确实有目标帧、只是**被本机按设计丢弃**（往上表第 1、2 行查）；若 Y 是好几秒，才是"流里没有可用目标帧"这一大类。
**★ 线上真相工具**：`k230 raw 10` 不看缓存、只把收到的字节按帧原样打出来（hex + 解码 + 校验判决），是这套分诊里最不依赖任何假设的一件。

对照两个现成工具：`k230`（**不清**缓存）若还能显示"缓存目标：类别 X（Yms 前）" ⇒ 帧**曾经**到过，Y 就是"上位机最后一次报它"到现在的差距；
`k230 live 20` 若一帧目标都不打印、只有每秒"无目标+N"行 ⇒ 是"报 0x00 / 帧越界 / 链路断"里的一条。
**★ 30 秒对照实验**：复现时**先不要动物块**，跑 `read 10` + `k230` + `k230 raw 10` 把证据留下；再把物块挪一下重跑一次。
若"挪一下"就恢复 ⇒ 上位机重新识别/重挑目标后就好了 ⇒ 指向上面第 1、2 行（帧在说无目标 / 帧越界），而不是链路。

**★"抓完之后有时自己回零校准" / "连夹持点都到不了"分诊（1008c 起，与产品同口径）**：

| 板上打印 | 含义 | 处置 |
|---|---|---|
| 运动中一行 `[INFO] 限位毛刺：只压住 Nms 就松开（< 10ms 确认窗）…不停、不作废` | 舵机/电机换向的电流尖峰耦合进限位线（**机械上没碰开关**）= 现场"抓完自己回零"的源头；产品同口径**忽略**它 | 正常，不用管（1008c 的行为就长这样）。若这一行**频繁**出现 ⇒ 查舵机/电机线与限位线走线（并行/捆一起）与地线；**N 就是毛刺真实时长**（判断要不要动确认窗靠它） |
| `[WARN] 撞限位（X/Y 被连续压住 ≥10ms）= 真撞：已急停 + XY 记账作废` | 开关**真被压住**（机械事实）：坐标已漂，或贴边件顶到了。产品口径：真撞 ⇒ 急停 + 记账作废 ⇒ **下一件开工前自动重新回零**（"抓完自己回零校准"就是它；**撞≠顺带校准**，撞 = 那件作废 + 白回零一次）。**故意用 `bx`/`j` 压开关试限位也会走这套**（10ms 后自动急停 + 记账作废；测完 `homex`+`homey` 即可） | `lim` 看是哪一路电平压着、`p` 看当前坐标；挪开或 `homex`+`homey` 重定 |
| `[GOTO] … 在极限位夹取带内——钳到 0 照样伸爪` / `… 按保护边距回拉到 -3` | **正常**：与产品 `Sort_DoCycle` 同口径的"够得着就去夹"（产品每件都这么算；边距 2026-10-10 由 5 缩到 3mm） | 照走；爪落极限位 ⇒ **可能夹偏/抓空**（用户已接受）。嫌计数虚增就调小 `DBG_CFG_PROD_CLAMP_BAND_MM`——**必须与产品 `CFG_XY_*_CLAMP_BAND_MM` 同值改** |
| `[FAIL] X/Y 超出极限位夹取带 / 低于工作区下限 / 超出夹爪延伸带` | 目标**真的够不着**（带外）⇒ 产品会**整件作废、机器一动不动** | 把物块往托盘里挪；若物块明明在托盘里仍被判"够不着" ⇒ 视觉→机械映射偏了（核 `CFG_VISION_ORIGIN_*`/符号/比例，见 §15.3） |

一句话口径：**毛刺不停不作废、真撞停+作废、贴边钳位照夹、带外整件作废**——四条与产品逐条相同
（依据与仿真演示见 `台架调试记录与结论.md` §8.11）。
